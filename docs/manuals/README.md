# SMU 프로그래밍 매뉴얼 보관 폴더

이 폴더는 Tektronix (Keithley) 2450 / 2460 / 2461 / 2470 시리즈의 프로그래밍 매뉴얼(Reference Manual, User Manual, Application Notes)을 보관하는 곳입니다.

## 폴더 안내
- `2450/`: 2450 SourceMeter (200V, 1A, 20W) 매뉴얼
- `2460/`: 2460 High Current SourceMeter (100V, 7A, 100W) 매뉴얼
- `2461/`: 2461 High Current Pulse SourceMeter (100V, 10A Pulse / 7A DC, Dual Digitizer) 매뉴얼
- `2470/`: 2470 High Voltage SourceMeter (1100V, 1A, 20W) 매뉴얼
- `common/`: 2400 그래픽 시리즈 공통 SCPI / TSP 명령어 가이드, TriggerFlow 및 TSP-Link 관련 문서

> 매뉴얼 파일(PDF, Markdown, TXT 등)을 각 폴더에 넣어주시면, 해당 매뉴얼의 SCPI/TSP 명령어 규격과 모델별 제약 조건(전압/전류/펄스 한계 등)을 참조하여 드라이버 및 심화 기능 코드를 정확하게 구현할 수 있습니다.
